# 🎅 FCalculator – Новогодний калькулятор 📱❄️

Весёлый новогодний калькулятор для Android с анимацией снежинок и живым подсчётом выражений.  
Идеально для праздничного настроения!

---

## ✨ Возможности
- Поддержка выражений (`6+7×5`)
- Автоматический подсчёт результата в реальном времени
- Корректный приоритет операций
- Форматирование больших чисел (`5.555555E10`)
- Плавная анимация при нажатии `=`
- Новогодние эффекты: падающие снежинки
