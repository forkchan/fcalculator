# 🎅 FCalculator – New Year Calculator 📱❄️
# 🎅 FCalculator – Новогодний калькулятор 📱❄️

Fun New Year calculator for Android with falling snow animation and live expression calculation.  
Perfect for a festive mood!  

Весёлый новогодний калькулятор для Android с анимацией снежинок и живым подсчётом выражений.  
Идеально для праздничного настроения!

---

## ✨ Features / Возможности
- Supports expressions (`6+7×5`) / Поддержка выражений (`6+7×5`)
- Automatic real-time calculation / Автоматический подсчёт результата в реальном времени
- Correct operator precedence / Корректный приоритет операций
- Large number formatting (`5.555555E10`) / Форматирование больших чисел (`5.555555E10`)
- Smooth animation when pressing `=` / Плавная анимация при нажатии `=`
- New Year effects: falling snowflakes / Новогодние эффекты: падающие снежинки

## ⚠️ Installation / Установка
Since the app is installed **not from Google Play**, you need to:  
1. Allow installation from unknown sources  
2. Open the downloaded APK  
3. Install the application  

Так как приложение устанавливается **не из Google Play**, при установке нужно:  
1. Разрешить установку из неизвестных источников  
2. Открыть скачанный APK  
3. Установить приложение
